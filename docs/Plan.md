# 开发计划与维护约定

源码版本仍为**0.1.7**，0.1.8已完成主轮UI与轻量化开发，正按§6补齐复核项，尚未发布。版本真源为`lib/version.mjs`；[docs/current-state.json](current-state.json)记录限定证据与发布历史。[README](../README.md)写入口，[指南](guide.md)写操作/预算，[维护指南](maintaining.md)写维护；本计划仅保留契约与待办。

## 1. 项目定位与交付状态

检查**已安装DSH插件**与目标版本的兼容性，提供源码位置、依据和覆盖限制。声明放行、激活、客户端到货、无发现或覆盖完整均不等于业务验收。

单Node判定内核；private根工作区的CLI、安装检查、批量、作者CI和健康执行器从源码运行。npm只交付`plugin/`的面板、tool、skill及内核，无CLI bin、不支持npx；源码安装须[构建完整tgz](../plugin/README.md#从源码构建安装)。

## 2. 现行判定与集成契约

仅保留不变量，操作、预算及实现细节见链接文档和契约真源。

### 2.1 证据与分析边界

AST按host/client/shared归属Context、服务及真实位置，入口遵循宿主、不猜路径；动态/变异/遮蔽/逃逸/异步/超限保守推断或弃权。能力守卫须控制调用，try/catch不作证明；不执行目标、不保存prompt/任意枚举。语义范围见[参数与生命周期](guide.md#参数与生命周期语义)，入口/源码图见[提取器维护](maintaining.md#提取器与探针维护)。

### 2.2 结论、影响与基线

确定性与实测/推断独立；ok且无已验证调用标vacuous并保留coverage。未观测不等于缺失，采样不执行getter或记录属性值，属性/字节/耗时/方法/原型预算超限标截断及未知，按实际消费服务归属覆盖限制；provide只是候选；必需inject须合格同目标absent，启用且可靠映射的FAILED/PENDING才形成fatal实测发现。声明遵循目标策略，精确豁免不放行非法字段。

[基线schema2](../lib/baseline.mjs)按目标及判定身份隔离、稳定配对，锁内比较/原子写入；失败/不完整/取消/卸载不推进，身份变化中性，证据减弱不称修复。无历史及未保存原因分别提示，坏/旧基线保留原件。状态目录私有，[锁恢复](guide.md#本地状态锁恢复)须显式确认并证明持有者退出。

### 2.3 报告结构与兼容策略

[报告schema1](../lib/contracts.mjs)：CLI kind=`plugin-compat-check/result`、HTTP kind=`plugin-compat-check/report`，tool保留summary/text及report/baseline/cache；字段自洽，不兼容变更升schema。普通退出码**0未发现冲突、1部分可用或未知、2不兼容、3工具/输入错误**。

处置元数据按报告/输入身份缓存派生上下文和已校验sidecar，每次仍核私有目录及文件指纹；修订/替换/损坏/权限变化、目标淘汰及卸载失效，保存重核当前输入与锁内原件。缓存按目标/输入/观测身份隔离，single-flight及worker队列有界；失效任务不得发布/写基线，失败保留旧成功及错误，卸载回收。宿主提取及纯判定/关系图/报告渲染/基线快照分别由10秒worker监督，共享普通队列，回收后由宿主重核身份并提交基线；服务索引避免逐服务重扫。服务引用20000、依赖/调用点各50000、插件2000，提取及计算回传各8MiB，超限报工具错误、不裁证据为成功。宿主列表1.5秒、输入检查12秒、单轮报告45秒、处置读取5秒、客户端请求50秒截止；取消/超时释放共享请求，迟到结果不得发布或提交基线。[完整导出](guide.md#面板与报告核实)不受筛选影响，issue-report禁读写基线，常见引号/大小写/嵌套凭据说明整字段隐藏，显式复制、不自动发帖，不保证完全脱敏；主报告及labels/直接提取/库存/到货辅助文本复用terminalText转义低信任字段，布局换行与JSON原始身份保留。[预算](guide.md#日常检查与源码交付)集中维护。

### 2.4 DSH接入要点

槽位为`settings.plugins.tab`、`plugins.detail.section / .badge`；无可靠身份不作包级判断。客户端用ModuleLoader id/factory，宿主不代构建；tool required为顶层数组、skill由provider注册。[入口与用法](../README.md#界面各板块怎么用)：左下角“更多”/用户头像→设置→内置插件→兼容性。

保留现有shadcn/Card/Fold架构：主结果→依赖关系→人工处置→升级预检；故障报告导出及折叠的证据说明并入主结果，归档/历史/健康导入归默认收起的高级工具，检查元信息页尾折叠，Separator分隔；主表/关系表、预检风险/两版本插件/输入制品及单插件发现均每页50项，关闭的只读明细延迟构建；筛选全量、导出完整。辅助表默认收起，覆盖/截断及未认证警告可见；文字/aria-expanded按钮支持键盘，升级表单收起保留输入，新增/变重风险默认展开。卡片及折叠标题统一16px内边距，标题与展开按钮垂直居中、按钮靠右；表单标签/输入/保存及表格/导出留出间距。字号14/13/12px，正文主色/注释灰色、主题适配；loader前两列至少240/280px、窄容器横滚。

UI固定文案及已知依赖/覆盖/预检/采样说明集中为中英韩词典，文件选择控件跟随插件语言；参数中的路径、标识符及未知证据原样保留。默认跟随宿主`lang`，可在本插件本机覆盖；未知语言回退英文。术语/无障碍标签同步，原始发现/诊断/人工依据及导出保留原文，切换不重置表单/草稿或改变判定。构建压缩词典重复键，不增加国际化运行依赖。

三槽位按目标共享2秒轮询，可见订阅、隐藏暂停取消，恢复核新鲜度，刷新合并/迟到响应丢弃；报告/派生复用，辅助面板近视区初始化、已访问编辑区保留，只读内容收起卸载，HMR/卸载回收资源。剩余边界见§6。[构建与真源](maintaining.md#维护入口与语法覆盖)复用宿主React、预编译压缩JS/CSS及[组件来源](../plugin/src/components/ui/PROVENANCE.md)，样式限定`.dsc-ui`；契约去重不得削弱校验/许可证/独立tgz，不直接改产物。

[HTTP](guide.md#本地http边界)限定报告/预检GET、处置JSON POST，本地/完整同源与标记检查后调用宿主`connection.requestRejection`；缺失/伪造/过期会话401，鉴权缺失/异常503，拒绝先于计算/写入。不自行管理宿主密钥，不承诺超出宿主会话的跨用户隔离或[OS沙箱](guide.md#安装与probe执行环境)。目录只认证登记精确版本/字节，漂移失败，未来/未知/自定义保持未认证；[新增目录](maintaining.md#api目录候选审查)另审并实机验收。

### 2.5 有限静态批量契约

[批量](guide.md#升级预检与有限批量)仅扫1–16项锁定精确版本/摘要、稳定验真的第三方本地包副本；拒绝链接/特殊文件/官方包，不下载或执行、不用probe/豁免/基线、不跨样本提供服务。保留发现/覆盖/诊断，总码先3再取最重0/1/2，previous须重扫且身份相容；手动Action仅扫固定合成样本。

### 2.6 真实故障回归与呈现

[限定回归](maintaining.md#真实插件回归)固定DSH/目录、五个制品及24项期望，先封存预测，后取独立HTTP/DOM/磁盘真值，区分静态、自然/受控故障及驱动错误，核对身份/时序/清理；不外推生态准确率，hash不作签名。下一步核实不猜替代API/修复版本或自动改配置，保留目标/时间/缓存/覆盖。

### 2.7 升级前静态预检契约

`runUpgradePreview`仅支持精确**0.2.0-rc.2、0.2.1-rc.2、0.2.1-rc.3**，其余读输入前退出3。同组私有字节分版本判定，捕获/分析/清理受监督，清理失败不成功；不安装/升级/执行宿主，不借运行时、豁免或普通缓存/基线。

[预检契约](../lib/upgrade-contract.mjs)的**0/1/2表示无/非致命/致命新增或变重风险，3表示无法预检**；旧风险及coverage/vacuous保留，ok仅指比较完成。CLI须nm/当前版本/upgrade-to，agent当前版本取宿主，返回upgradePreview、普通report为null。正文/目标/输入变化撤销旧比较，缓存/人工修订重读不撤销，过时响应丢弃。[互斥参数](guide.md#升级预检与有限批量)集中维护。

### 2.8 健康检查、依赖关系与人工处置

[健康执行器](guide.md#可选功能健康检查)默认review，显式run才安装验真制品并启动自有DSH/Chrome，仅有预算的同源GET/只读DOM断言；不接作者脚本或账户/模型配置，面板只导入历史JSON、不认证当前制品。[依赖图](guide.md#依赖关系与潜在影响)仅表示分端声明、候选及潜在路径。[处置记录](guide.md#发现的人工处置)绑定目标/源码/版本及判定身份，变化待重审；令牌/锁内合并/原子替换防陈旧写入，不隐藏发现、改判定/基线或授予豁免。处置显示类别/API/源码及依据摘要，按插件/人工状态筛选，主结果与处置按context/finding双向定位并打开正确分页；筛选保留草稿及完整原始风险。未保存草稿按原context/finding保留；轮询修订不重置输入/焦点，身份变化标过期、禁保存，支持复制后重新核实或显式放弃；仅保留当前页面会话，不自动迁移。[长期记录](guide.md#人工处置归档与本地历史报告)须显式确认、先完整备份再释放活动容量；归档/恢复只供参考，不自动恢复当前已复核，限额满后显式导出/移除。历史报告主动保存，身份相同才比较，证据减弱中性、风险增加优先；不推进基线、不自动收集。

### 2.9 插件作者CI

默认矩阵包含`0.2.0-rc.2`、`0.2.1-rc.2`、`0.2.1-rc.3`，对同一构建包只读快照判定。默认阻断全部发现/未知/覆盖不足/vacuous，显式策略不放行未知版本/工具错误；new须身份相容的已审查JSON，旧风险/覆盖保留。JSON/SARIF/JUnit/HTML保留完整证据及身份，超预算不得截断成功；策略码与内核码分开，0仅表示策略满足。见[作者流程](author-ci.md)。
