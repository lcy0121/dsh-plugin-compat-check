# 开发计划与维护约定

源码版本仍为**0.1.7**，0.1.8已完成主轮UI与轻量化开发，正按§6补齐复核项，尚未发布。版本真源为`lib/version.mjs`；[docs/current-state.json](current-state.json)记录限定证据与发布历史。[README](../README.md)写入口，[指南](guide.md)写操作/预算，[维护指南](maintaining.md)写维护；本计划仅保留契约与待办。

## 1. 项目定位与交付状态

检查**已安装DSH插件**与目标版本的兼容性，提供源码位置、依据和覆盖限制。声明放行、激活、客户端到货、无发现或覆盖完整均不等于业务验收。

单Node判定内核；private根工作区的CLI、安装检查、批量、作者CI和健康执行器从源码运行。npm只交付`plugin/`的面板、tool、skill及内核，无CLI bin、不支持npx；源码安装须[构建完整tgz](../plugin/README.md#从源码构建安装)。

## 2. 现行判定与集成契约

仅保留不变量，操作、预算及实现细节见链接文档和契约真源。

### 2.1 证据与分析边界

AST按host/client/shared归属Context、服务及真实位置，入口遵循宿主、不猜路径；动态/变异/遮蔽/逃逸/异步/超限保守推断或弃权。能力守卫须控制调用，try/catch不作证明；不执行目标、不保存prompt/任意枚举。语义范围见[参数与生命周期](guide.md#参数与生命周期语义)，入口/源码图见[提取器维护](maintaining.md#提取器与探针维护)。

### 2.2 结论、影响与基线

确定性与实测/推断独立；ok且无已验证调用标vacuous并保留coverage。未观测不等于缺失，采样不执行getter、provide只是候选；必需inject须合格同目标absent，启用且可靠映射的FAILED/PENDING才形成fatal实测发现。声明遵循目标策略，精确豁免不放行非法字段。

[基线schema2](../lib/baseline.mjs)按目标及判定身份隔离、稳定配对，锁内比较/原子写入；失败/不完整/取消/卸载不推进，身份变化中性，证据减弱不称修复。无历史及未保存原因分别提示，坏/旧基线保留原件。状态目录私有，[锁恢复](guide.md#本地状态锁恢复)须显式确认并证明持有者退出。

### 2.3 报告结构与兼容策略

[报告schema1](../lib/contracts.mjs)：CLI kind=`plugin-compat-check/result`、HTTP kind=`plugin-compat-check/report`，tool保留summary/text及report/baseline/cache；字段自洽，不兼容变更升schema。普通退出码**0未发现冲突、1部分可用或未知、2不兼容、3工具/输入错误**。

缓存按目标/输入/观测身份隔离，single-flight及worker队列有界；失效任务不得发布/写基线，失败保留旧成功及错误，卸载回收。[完整导出](guide.md#面板与报告核实)不受筛选影响，issue-report禁读写基线，显式复制、不自动发帖，不保证完全脱敏；终端转义控制字符，JSON保留身份。[预算](guide.md#日常检查与源码交付)集中维护。

### 2.4 DSH接入要点

槽位为`settings.plugins.tab`、`plugins.detail.section / .badge`；无可靠身份不作包级判断。客户端用ModuleLoader id/factory，宿主不代构建；tool required为顶层数组、skill由provider注册。[入口与用法](../README.md#界面各板块怎么用)：左下角“更多”/用户头像→设置→内置插件→兼容性。

保留现有shadcn/Card/Fold架构：主结果前置、升级预检独立卡、说明归页尾，Separator分隔；主表/关系表50行分页，筛选全量、导出完整。辅助表默认收起，覆盖/截断及未认证警告可见；文字/aria-expanded按钮支持键盘，升级表单收起保留输入，新增/变重风险默认展开。字号14/13/12px，正文主色/注释灰色、主题适配；loader前两列至少240/280px、窄容器横滚。

三槽位按目标共享2秒轮询，可见订阅、隐藏暂停取消，恢复核新鲜度，刷新合并/迟到响应丢弃；报告/派生复用，辅助面板近视区初始化、已访问编辑区保留，只读内容收起卸载，HMR/卸载回收资源。剩余边界见§6。[构建与真源](maintaining.md#维护入口与语法覆盖)复用宿主React、预编译压缩JS/CSS及[组件来源](../plugin/src/components/ui/PROVENANCE.md)，样式限定`.dsc-ui`；契约去重不得削弱校验/许可证/独立tgz，不直接改产物。

[HTTP](guide.md#本地http边界)限定报告/预检GET、处置JSON POST，本地/完整同源检查及标记头不替代鉴权，不承诺跨用户隔离或[OS沙箱](guide.md#安装与probe执行环境)。目录只认证登记精确版本/字节，漂移失败，未来/未知/自定义保持未认证；[新增目录](maintaining.md#api目录候选审查)另审并实机验收。

### 2.5 有限静态批量契约

[批量](guide.md#升级预检与有限批量)仅扫1–16项锁定精确版本/摘要、稳定验真的第三方本地包副本；拒绝链接/特殊文件/官方包，不下载或执行、不用probe/豁免/基线、不跨样本提供服务。保留发现/覆盖/诊断，总码先3再取最重0/1/2，previous须重扫且身份相容；手动Action仅扫固定合成样本。

### 2.6 真实故障回归与呈现

[限定回归](maintaining.md#真实插件回归)固定DSH/目录、五个制品及24项期望，先封存预测，后取独立HTTP/DOM/磁盘真值，区分静态、自然/受控故障及驱动错误，核对身份/时序/清理；不外推生态准确率，hash不作签名。下一步核实不猜替代API/修复版本或自动改配置，保留目标/时间/缓存/覆盖。

### 2.7 升级前静态预检契约

`runUpgradePreview`仅支持精确**0.2.0-rc.2、0.2.1-rc.2、0.2.1-rc.3**，其余读输入前退出3。同组私有字节分版本判定，捕获/分析/清理受监督，清理失败不成功；不安装/升级/执行宿主，不借运行时、豁免或普通缓存/基线。

[预检契约](../lib/upgrade-contract.mjs)的**0/1/2表示无/非致命/致命新增或变重风险，3表示无法预检**；旧风险及coverage/vacuous保留，ok仅指比较完成。CLI须nm/当前版本/upgrade-to，agent当前版本取宿主，返回upgradePreview、普通report为null。正文/目标/输入变化撤销旧比较，缓存/人工修订重读不撤销，过时响应丢弃。[互斥参数](guide.md#升级预检与有限批量)集中维护。

### 2.8 健康检查、依赖关系与人工处置

[健康执行器](guide.md#可选功能健康检查)默认review，显式run才安装验真制品并启动自有DSH/Chrome，仅有预算的同源GET/只读DOM断言；不接作者脚本或账户/模型配置，面板只导入历史JSON、不认证当前制品。[依赖图](guide.md#依赖关系与潜在影响)仅表示分端声明、候选及潜在路径。[处置记录](guide.md#发现的人工处置)绑定目标/源码/版本及判定身份，变化待重审；令牌/锁内合并/原子替换防陈旧写入，不隐藏发现、改判定/基线或授予豁免。

### 2.9 插件作者CI

默认矩阵包含`0.2.0-rc.2`、`0.2.1-rc.2`、`0.2.1-rc.3`，对同一构建包只读快照判定。默认阻断全部发现/未知/覆盖不足/vacuous，显式策略不放行未知版本/工具错误；new须身份相容的已审查JSON，旧风险/覆盖保留。JSON/SARIF/JUnit/HTML保留完整证据及身份，超预算不得截断成功；策略码与内核码分开，0仅表示策略满足。见[作者流程](author-ci.md)。

## 3. 开发与文档维护约定

先复现再修，保留行为回归，不重建快照求绿；`test/__baseline-versions.json`的判据变更须单独审查/提交。默认测试仅用只读profile副本；真实执行只清自有目录/PID组，账户、模型、发布及外部发帖另取授权。

§6仅列未完成事项，完成后并入前文并重排编号。维护检查核对版本/认证集合、链接、生成副本、许可证及语法矩阵；真实宿主、公共发布状态另验，历史明细留Git。

## 4. 验收范围

以[current-state](current-state.json)的精确输入、版本、制品及平台为限，不外推生态/业务或Windows认证。0.1.8本轮验收为macOS arm64、DSH 0.2.1-rc.3及同一tgz，合成性能表征不代替真实试用；复核缺陷见§6。历史见`f5ec0d0:docs/current-state.json`及前序指针；正式发布须核对同一验收tgz、registry及release附件。

## 5. 验证入口

运行`npm test`、`npm run check`、`node plugin/scripts/prepublish-check.mjs`（不发布）；成功TAP交给`tools/update-current-state.mjs --test-summary`更新计数。`tools/meta-check.mjs --json`只读查GitHub/npm，候选高于registry为预期差异，取数失败不是通过。[真实集成与同一tgz验收](guide.md#工程与真实集成)。

## 6. 后续工作

仅列未完成事项，优先级不是漏洞评级；现行UI见§2.4。2026-10-26复核的已复现缺陷在条目内注明；P3为后续扩展，不默认纳入0.1.8发布范围。

1. **P1：0.1.8报告超时与失败恢复。** 已复现`pluginManager.list()`不返回会拖住报告请求，客户端刷新随共享在途请求排队。为宿主服务、整次计算及客户端请求补截止时间/取消；失败保留旧报告并标明不可用，不伪造空成功。验冷启动、后台/手动刷新、卸载、迟到响应及故障后恢复。
2. **P1：0.1.8人工处置草稿保护。** 已复现报告/源码身份变化会清空未保存的“核实依据”。保留并标记过期草稿，提供复制或显式重新核实后迁移；不自动保存到新finding。验后台轮询、上下文切换、旧保存响应及折叠/焦点，避免丢失输入或陈旧写入。
3. **P1：继续交互评测与小规模真实用户试用。** 闭环定位、字体/字色、展开、主题及窄容器反馈，记录安装→理解→定位的误读、失败、误报、分享障碍与耗时。合成样例不代替真实试用，保留coverage/vacuous；联系、收集、公开分别授权，不默认遥测。
4. **P2：0.1.8故障报告脱敏补齐。** 已用假loader错误复现：`password=值`隐藏，JSON带引号字段可能漏脱敏。补常见引号/大小写/嵌套格式及对应回归，覆盖CLI和面板同一导出链；敏感说明整字段隐藏，保留安全身份/位置、显式预览复制及“不保证完全脱敏”的边界。
5. **P2：本地接口鉴权加固。** 自有rc.3预览仅带标记头、无登录凭据仍返回报告元数据；当前是跨站请求防护，不提供跨用户隔离。核对并复用宿主正式鉴权，覆盖报告/元数据/预检/处置；验缺失、伪造、过期凭据和同源恢复，不把本机边界外推为公网漏洞。
6. **P2：0.1.8预检及单插件大列表开销。** 主表/关系表已每页50行，预检风险分组、两版本明细及单插件发现仍全量构建。补分页/分批及只读内容延迟生成，测大样本元素数/计算量；保留风险总数、默认重点、覆盖/来源、完整导出与既有卡片/按钮架构。
7. **P2：运行时服务采样预算补齐。** 已复现`serviceShape`仅限制函数数量，1万普通属性仍全收且未标截断。补属性总数、结果字节和耗时预算，明确截断/未知；验普通属性、访问器、深原型及大对象，不执行getter、不记录属性值，不把未采样当作缺失。
8. **P2：元数据轮询后端缓存。** 元数据返回前仍构建处置上下文、读取/校验记录；测大报告与近上限sidecar的I/O、派生及校验开销，按报告身份/记录变化缓存。保存仍须重新核实当前输入；保留坏文件、修订变化、失败恢复、目标隔离与卸载边界。
9. **P2：人工处置定位与筛选。** 目前主要靠插件名和发现序号对应。显示类别、API、源码位置及核实摘要，提供主结果↔处置定位、插件/状态筛选；以finding身份关联，验排序/分页/筛选后仍对应正确，不因处置状态隐藏原始风险。
10. **P2：0.1.8专项UI持续验收。** 将`DSC_UI018_ACCEPTANCE=1`、`DSC_UI018_P2=1`纳入真实Linux浏览器CI，保存主题、列宽、键盘、卸载恢复和大列表分页/筛选/导出证据；避免只依赖本地macOS记录。结果绑定精确提交、宿主与tgz，不扩大业务或平台认证。
11. **P2：跟进上游验收。** 按2026-10-25记录跟进[market#932](https://github.com/dsh-market/dsh-market/issues/932)（已关闭，双查询失败处理待验）、[1024#22](https://github.com/imsai-sh/dsh-1024store/issues/22)（待npm安装方式）、[0xsline#717](https://github.com/0xsline/awesome-deepseek-harness/pull/717)（未合并）。变化后再验，反馈另取授权，不重复发帖；历史状态不认证当前安装。
12. **P2：Windows真实验收（依环境条件暂缓）。** 条件具备后验证路径、安装、回收、权限、打包/诊断及自有资源清理；此前保持未验收。
13. **P3：按职责拆分大模块。** 逐步拆分宿主入口的HTTP/缓存/处置及客户端报告/预检逻辑，降低维护误改风险；保持现有UI架构、导出、加载和错误契约，沿用行为回归及独立tgz验证，不为拆分改变判据。
14. **P3：人工处置长期记录管理。** 增加历史归档/导出和容量提示，处理1MiB/1000条上限后的新记录保存；归档须用户明确操作并保留可回溯身份，不静默删除历史、不扩大上限掩盖开销，恢复或导入不能冒充当前已复核。
15. **P3：UI多语言。** 将固定中文文案集中为字典，跟随宿主语言；同步中英韩术语、状态、无障碍标签及README，验长翻译、窄容器与主题，保留证据含义和既有组件风格。
16. **P3：本地历史报告与趋势。** 支持用户主动保存快照、跨次检索及升级前后对照；校验目标/版本/工具/规则/目录身份，不可比时中性显示。区分静态推断与实测，历史快照不认证当前目标；分享继续显式预览，不默认上传或遥测。
